# Redistribution and acknowledgements

**Draft — not cleared for public distribution.** A GitHub repository can be publicly visible immediately, but that does not mean everything uploaded to it can legally be redistributed. The 45 `.ZDL` files require a source-provenance audit first.

The project should verify whether compiled binaries include Zoom-derived handlers, proprietary firmware code, third-party copyrighted artwork, or other code that the project cannot license. Review upstream licenses and keep **legally required copyright notices and attribution** where code has actually been reused. Independently written effect code is a separate category.

A product being discontinued does not make its software public domain. **No blanket MIT license is asserted for the `.ZDL` binaries in this draft.** A license for original project tools/source code can be chosen after authorship and rights are documented, and should clearly state the covered files.

The `inspired by` entries in [`effects.csv`](effects.csv) are descriptions of sonic influences, not statements of endorsement, affiliation, or copying. **A large reference archive or list of research URLs is not required simply to name a musical inspiration.** If an actual third-party implementation or asset is incorporated, preserve the attribution/license notices its license requires. No source firmware or TI compiler is distributed in this draft.

For now, keep this ZIP private. The public-facing repository design is complete, but the binaries should be published only once the rights audit has been resolved.
